# Excursion

Codecademy Excursion landing-page project.

## Run locally
Open `index.html` in a browser.

## Video
For a fully local project, download the official Codecademy video and save it as:
`resources/videos/excursion.mp4`

The page also contains the official Codecademy video URL as a fallback.
